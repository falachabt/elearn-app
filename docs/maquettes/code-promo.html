Code promo du Pass

Les états de l'écran E2 (Paiement) quand l'élève a un code promo : saisie, vérification, code appliqué avec prix barré, retrait, erreurs, et paiement à 0 FCFA. E2 ne montrait que le lien « J'ai un code promo » : on garde cet écran et on n'ajoute que ce que le code change. Essaie le prototype ci-dessous.

Offre choisie sur E1
Thème
Codes de démonstration

Touche un code pour le copier dans le champ, ou tape-le. Tout autre code est « inconnu ». Cinq essais ratés de suite donnent « Trop d'essais ».

Spec pour le dev

  

    
Règles retenues
    
      
  • Un seul code par paiement. Pour en changer, on retire le code appliqué, puis on en saisit un autre.
    • 
      
  • Valable pour le Pass seulement (semaine, mois, concours). Pas pour les crédits ni les autres achats.
    • 
      
  • Le prix est toujours recalculé côté serveur : l'app affiche ce que le serveur renvoie et ne l'envoie jamais.
    • 
      
  • Le code est vérifié au toucher sur « Appliquer » ou sur la touche OK du clavier, pas à chaque lettre. Une seule requête à la fois.
    • 
      
  • Le code est mis en majuscules, sans espaces, 20 caractères au plus (lettres, chiffres, tiret).
    • 
      
  • La réduction est « réservée » à la commande ; used_count n'augmente qu'au paiement confirmé par le serveur (issue #7).
    • 
    

    
Comportements
    
      
  • Ouverture : « J'ai un code promo » remplace le lien par le champ, ouvre le clavier, met le focus. L'écran défile pour garder le champ au-dessus du clavier.
    • 
      
  • Annuler : referme le champ, efface le texte, rend le lien.
    • 
      
  • Appliquer : blanc et grisé tant que le champ est vide ; vert dès qu'il y a du texte. « Payer » passe alors en blanc : un seul bouton vert par écran. Pendant la vérification : « Vérification… », champ figé.
    • 
      
  • Appliqué : le résumé affiche l'ancien prix barré, le nouveau prix et le badge « -20 % » ou « -500 FCFA », plus « Tu économises … ». Une ligne montre le code et un bouton « Retirer ».
    • 
      
  • Retirer : sans confirmation, le prix d'origine revient, le lien « J'ai un code promo » revient.
    • 
      
  • Erreur : le texte reste dans le champ, la bordure et le message passent en corail ; le message est annoncé au lecteur d'écran. Dès que l'élève modifie le texte, l'erreur disparaît. Payer au prix normal reste possible à tout moment.
    • 
      
  • Changement d'offre : si l'élève revient sur E1 et choisit une autre offre, le code est revérifié pour cette offre.
    • 
    

    
Messages d'erreur

      
CasMessage

      
inconnuCe code n'existe pas. Vérifie les lettres et réessaie.

      
expiréCe code a expiré le 30 sept.

      
épuiséCe code a déjà été utilisé le maximum de fois.

      
offreCe code est valable pour le Pass concours, pas pour le Pass mois. Bouton « Choisir le Pass concours ».

      
réseauPas de réseau. Connecte-toi pour appliquer ton code. Bouton « Réessayer ».

      
trop d'essaisTrop d'essais. Réessaie dans 1 minute.

    
Paiement à 0 FCFA
    
      
  • Quand le prix final est 0 : plus d'opérateur ni de numéro. Une carte verte dit « Rien à payer » et le bouton devient « Activer mon Pass ».
    • 
      
  • Aucune demande Mobile Money n'est envoyée : le serveur active le Pass directement, dans la même transaction que le code consommé. Le compte connecté reste obligatoire.
    • 
      
  • Le reçu (E4) montre le montant 0 FCFA et le code utilisé.
    •

États à tester
    
      
  • Point de départ, ouvert vide, avec texte, vérification, appliqué en %, appliqué en FCFA, gratuit.
    • 
      
  • Les six erreurs, puis correction du texte qui efface l'erreur.
    • 
      
  • Retrait du code, changement d'offre, double appui sur Appliquer (une seule requête).
    • 
      
  • Clair et sombre, texte système à 130 %, clavier ouvert sur un petit écran, lecteur d'écran.

    
Accessibilité et style
    
      
  • Champ avec libellé « Code promo », majuscules automatiques, sans correction automatique, touche clavier « OK » = Appliquer.
    • 
      
  • L'état « appliqué » et les erreurs portent un texte et une icône, jamais la couleur seule.
    • 
      
  • Cibles de 48 px, texte noir sur le jaune du badge, aucun emoji, icônes Lucide.
    • 
      
  • Le résumé annonce « Prix 2 000 FCFA au lieu de 2 500 FCFA ».
