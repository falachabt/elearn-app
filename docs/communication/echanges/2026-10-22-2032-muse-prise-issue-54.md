## Origine

Première tâche proposée par `docs/communication/PROMPT-MUSE.md` (section 6), confirmée par Benny le 22 octobre 2026. Aucune zone TOEIC touchée : le démarrage web et le service worker sont isolés du profil TOEIC.

## Constat précisé par Benny (22 octobre, pour le constat du 7 octobre)

La PWA était installée. Sans internet, au lancement à froid, elle restait bloquée sur l'écran de l'icône (splash du manifeste), puis affichait la page « pas d'internet » du navigateur. C'est donc la navigation elle-même qui n'est pas servie par le service worker : soit il n'est pas actif sur ce téléphone, soit son secours de navigation ne trouve pas la page en cache.

## Ce qui est déjà vérifié (lecture seule, 22 octobre)

- Production (`app.elearnprepa.com`) : `/sw.js` servi en `application/javascript`, `Cache-Control: no-cache`, `Service-Worker-Allowed: /`, contenu identique au dépôt (version v2, commit `ee89d84`). La page `/` contient bien l'enregistrement du worker et la balise du bundle.
- Le code du worker couvre en théorie le besoin : coquille et fichiers JS/CSS mis en cache à l'installation, navigation réseau d'abord avec secours sur la page en cache, fichiers statiques cache d'abord. Tests unitaires présents (`src/__tests__/serviceWorker.test.ts`).

## Plan

1. Reproduire en local : export web, service par un serveur local, navigateur Chromium (Playwright) : visite en ligne, worker actif, puis hors ligne et démarrage à froid. Dire si le défaut se reproduit avec le code actuel.
2. Si le défaut se reproduit : test qui échoue, correctif, test qui passe, validation locale (`npm run valider`), commits `muse:` regroupés.
3. Si le défaut ne se reproduit pas avec le code actuel : vérifier les hypothèses restantes (ancien worker ou ancien cache resté sur le téléphone, installation depuis un autre navigateur) et demander à Benny un retest sur la version en ligne, PWA réinstallée.
4. Décision de Benny, écrite dès le départ : si l'ouverture hors ligne s'avère vraiment impossible dans des conditions correctes, ce n'est pas bloquant ; fermer la #54 en documentant pourquoi, et passer à une autre tâche.
